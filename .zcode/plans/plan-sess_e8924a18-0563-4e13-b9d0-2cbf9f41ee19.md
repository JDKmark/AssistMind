## phase7：AssistMind 电商智能客服（Agent 业务操作版）

### 叙事定位（回答"这是智能客服吗" + 命名）
**产品 = AssistMind，定位电商智能客服系统**（不是商城系统，不需要虚构商城名）。核心场景：电商用户对话（商品咨询/订单查询/退换货/物流/优惠）由 RAG 客服（faq）+ ToolAgent（task）承接；**Agent 亮点 = 业务操作工具链**：用户"我要退货"→ Agent 查订单 → 校验状态 → 走退款申请 → 生成售后工单 → 告知结果。多轮对话 + 工具调用 + 业务闭环（售前→售后）。

**运维诊断（Ops）降级**：保留在代码库，README 作为"扩展能力/技术底座"章节，不占客服主叙事。

### 四类问题话术
1. **要不要做**：客服自动化（常见咨询提效）+ Agent 最优解（售后操作需多轮工具编排：查单→校验→退款→建单，规则/RAG 无法完成）+ 增量（业务闭环可执行，不只答话术）
2. **怎么做**：五层——任务定义（意图路由）/编排（ToolAgent ReAct + LangGraph）/能力层（MCP 13 工具）/细节策略（降级/CRAG/断路器/语义缓存）/产品体验（SSE 流式 + 工具过程可视化）
3. **怎么迭代**：RAGAS 调优案例（0.53→0.55、弱项 0.65→0.938）+ 工具调用成功率评估迭代
4. **怎么验证**：客服 QA RAGAS + 工具调用成功率 + 单次对话成本核算

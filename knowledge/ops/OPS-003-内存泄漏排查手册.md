# OPS-003：内存泄漏（Memory Leak）排查手册

## 症状
- 内存占用持续爬升直至接近上限，触发 OOM
- 日志出现 OutOfMemoryError / GC overhead limit exceeded
- 实例频繁自动重启，服务间歇性不可用

## 常见根因
1. 缓存/会话数据无 TTL 或容量上限，无限增长
2. 静态集合持有对象引用未释放
3. 线程池/连接池对象泄漏

## 排查步骤
1. 查看告警：内存类告警（memory_usage）
2. 查看指标：内存占用曲线是否单调上升、GC 频率
3. 查看日志：搜索 OutOfMemoryError / GC / heap space 关键线索
4. 查看变更记录：排查故障前最近一次发布（是否引入缓存逻辑）

## 恢复动作
- 为缓存设置 TTL 与最大容量（如 LRU）
- 紧急时重启实例临时恢复，再定位泄漏点修复

# OPS-001：数据库连接池耗尽（Connection Pool Exhausted）排查手册

## 症状
- 服务接口大面积超时，错误日志出现「Connection is not available, request timed out」
- 连接池监控 active 连接数 = max_pool_size，waiting 数持续增长
- 下游服务同步调用报「Remote call failed」或「upstream timeout」

## 常见根因
1. 配置变更错误缩小连接池（如 max_pool_size 从 50 调成 10）
2. 慢 SQL 或未释放连接导致连接被长期占用
3. 突发流量超过连接池容量

## 排查步骤
1. 查看告警：确认哪个服务哪个指标触发告警
2. 查看指标：连接池使用率、等待数、下游接口错误率与延迟
3. 查看日志：搜索 connection pool / pool stats / timed out 关键线索
4. 查看变更记录：排查故障前最近一次配置变更或发布

## 恢复动作
- 回滚或调大连接池参数（如 max_pool_size 恢复为 50）
- 重启受影响实例让连接池重建
- 对同步调用增加超时与熔断，避免故障扩散

# 售后服务政策

> 适用对象：电商客服（人工 + 机器人）。本文档定义退货/退款业务规则与处理流程，
> 数据字段锚定 mall.sql 表结构（`oms_order_return_apply` / `oms_order_return_reason` /
> `oms_order_setting` / `oms_order`），数值口径为本项目自建演示规则。

## 1. 退换货总原则

- 商品自签收次日起 **7 天内** 支持无理由退货（法律法规另有规定的商品除外）。
- 申请退货的前提：订单已完成支付且处于可售后状态（`oms_order.status` 为 2 已发货 或 3 已完成，
  且未超过 `oms_order_setting.finish_overtime` 自动完成交易天数，演示配置 30 天）。
- 以下情况不支持无理由退货：定制类商品、已激活/已拆封影响二次销售的电子产品、
  一次性密封商品已破损、人为损坏商品。

## 2. 退货申请状态机（oms_order_return_apply.status）

| 状态值 | 含义 | 客服动作 |
|---|---|---|
| 0 | 待处理 | 用户提交申请后等待商家审核，客服需在 24 小时内处理 |
| 1 | 退货中 | 审核通过，用户寄回商品，物流在途 |
| 2 | 已完成 | 商家收到退货并验收通过，退款完成 |
| 3 | 已拒绝 | 商家驳回申请（需填写处理备注 handle_note），用户可修改后重新提交 |

状态流转：0 待处理 → 1 退货中（审核通过）或 3 已拒绝（驳回）；1 退货中 → 2 已完成（验收通过）。

## 3. 申请单关键字段（oms_order_return_apply）

- `order_sn`：原订单编号；`member_username`：申请会员账号；`create_time`：申请时间。
- `return_amount`：退款金额，默认 = 商品实际支付单价 × 退货数量（product_real_price × product_count）。
- `reason`：退货原因（从 oms_order_return_reason 中选择）；`description`：问题描述。
- `proof_pics`：凭证图片，多张以逗号分隔。
- `handle_man / handle_note / handle_time`：处理人、处理备注、处理时间。
- `receive_man / receive_time / receive_note`：收货人、收货时间、收货备注。

## 4. 常见退货原因（oms_order_return_reason.name，status=1 为启用）

1. 质量问题
2. 商品破损
3. 商品与描述不符
4. 发错货
5. 尺寸/规格拍错（7 天无理由）
6. 不喜欢/不想要（7 天无理由）

客服引导用户选择原因时：质量问题 / 破损 / 描述不符 / 发错货属商家责任（退货运费商家承担），
其余属用户责任（退货运费用户承担）。

## 5. 退货与退款流程

1. 用户在订单详情发起退货申请：选择原因（reason）、填写描述（description）、上传凭证（proof_pics）。
2. 商家审核：通过 → 状态流转为 1 退货中；驳回 → 状态流转为 3 已拒绝（附 handle_note）。
3. 用户按系统提供的退货地址寄回商品，并登记寄回物流信息。
4. 商家收货验收（receive_time / receive_note），通过后状态流转为 2 已完成。
5. 退款：验收通过后 **3 个工作日内** 原路退回（支付宝/微信，见 oms_order.pay_type）。

## 6. 运费承担规则

| 场景 | 退货运费承担方 |
|---|---|
| 7 天无理由（不喜欢/拍错等） | 用户承担 |
| 质量问题 / 破损 / 发错货 | 商家承担（用户先行垫付，退款时一并返还） |
| 附赠「免费包邮」服务（pms_product.service_ids 含 3）的商品 | 仅首程运费免，退货运费仍按上述规则执行 |

## 7. 退款时限承诺

- 审核时效：申请提交后 24 小时内处理（演示承诺）。
- 退款到账：验收通过后 3 个工作日内原路退回（带「快速退款」服务商品 24 小时内，见服务承诺与话术）。
- 订单处于「已发货未收货」时，可引导用户拒收：商家确认退货后直接退款，无需寄回流程，运费商家承担。

## 8. 客服答复示例（退货咨询）

- 「能退货吗」→ 先确认商品是否在 7 天内、是否符合无理由条件，再引导提交申请并选择对应 reason。
- 「退款多久到账」→ 验收通过后 3 个工作日内原路退回，具体到账时间以支付渠道为准。
- 「运费谁出」→ 按第 6 节规则答复，说明可上传凭证（proof_pics）佐证。
- 「为什么被拒绝」→ 转述 handle_note 中的拒绝原因，说明可补充凭证后重新提交。

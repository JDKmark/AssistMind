# 价格与优惠规则

> 适用对象：电商客服（人工 + 机器人）。价格构成与促销/优惠叠加规则，
> 数据字段锚定 mall.sql 表结构（`pms_product` / `pms_product_full_reduction` /
> `pms_product_ladder` / `sms_coupon` / `ums_integration_consume_setting` / `oms_order`）。

## 1. 价格字段（pms_product）

- `price`：销售价（展示价）。
- `original_price`：市场价（划线价，仅用于展示对比，不作为结算依据）。
- `promotion_price`：促销价格（promotion_type=1 时生效）。

## 2. 促销类型（pms_product.promotion_type）—— 单选互斥

| 值 | 含义 | 定价依据 |
|---|---|---|
| 0 | 没有促销，使用原价 | price |
| 1 | 使用促销价 | promotion_price |
| 2 | 使用会员价 | 会员等级价格（见会员与积分规则） |
| 3 | 使用阶梯价格（只针对同商品） | pms_product_ladder |
| 4 | 使用满减价格（只针对同商品） | pms_product_full_reduction |
| 5 | 限时购 | sms_flash_promotion_product_relation.flash_promotion_price |

同一商品同一时间只能启用一种促销类型：促销价与满减、阶梯价、限时购互斥。
限时购受 `promotion_start_time` / `promotion_end_time` 时间窗约束，`promotion_per_limit` 为活动限购数量。

## 3. 满减与阶梯（只针对同商品）

- 满减：pms_product_full_reduction，字段 `full_price`（满 X 元）/ `reduce_price`（减 Y 元）。
  多档满减同时配置时取用户可达的最优档，不可叠加。
- 阶梯：pms_product_ladder，字段 `count`（满足数量）/ `discount`（折扣）/ `price`（折后价）。
- 两者均只针对单个商品，不可跨商品合并计算（与优惠券的「全场通用」不同）。

## 4. 优惠券（sms_coupon）

- 类型 type：0 全场赠券 / 1 会员赠券 / 2 购物赠券 / 3 注册赠券。
- 门槛 min_point：使用门槛金额，0 表示无门槛。
- 使用范围 use_type：0 全场通用 / 1 指定分类 / 2 指定商品。
- 每人限领张数 per_limit；领取与使用记录见 sms_coupon_history
  （use_status：0 未使用 / 1 已使用 / 2 已过期）。

## 5. 积分抵扣（ums_integration_consume_setting）

| 字段 | 语义 | 演示默认值 |
|---|---|---|
| deduction_per_amount | 每一元需要抵扣的积分数量 | 100 积分抵 1 元 |
| max_percent_per_order | 每笔订单最高抵用百分比 | 50%（应付金额的一半） |
| use_unit | 每次使用积分最小单位 | 100（须按 100 的整数倍使用） |
| coupon_status | 是否可以和优惠券同用：0 不可以 / 1 可以 | 1 可以 |

商品限制：pms_product.use_point_limit 为该商品限制使用的积分数，超过该值的商品不可用积分抵扣。

## 6. 优惠叠加顺序与规则

订单金额计算顺序（对应 oms_order 金额字段）：

1. 商品级促销：促销价 / 会员价 / 阶梯价 / 满减 / 限时购 —— 取一种（promotion_type），
   结果反映在 `promotion_amount`（促销优化金额）。
2. 优惠券抵扣：`coupon_amount`，使用门槛按促销后的商品金额判断。
3. 积分抵扣：`integration_amount`，受 max_percent_per_order 与 use_unit 约束；
   是否可与优惠券同用由 ums_integration_consume_setting.coupon_status 控制（演示为可同用）。
4. 实付金额：`pay_amount = total_amount - promotion_amount - coupon_amount - integration_amount + freight_amount`；
   管理员调整订单使用的折扣金额记录在 `discount_amount`。

订单明细级分解（oms_order_item）：每行商品记录 promotion_amount / coupon_amount /
integration_amount / real_amount（该商品优惠后的分解金额），用于向用户解释单件商品优惠明细。

## 7. 常见价格咨询应答

- 「为什么和标价不一样」→ 查看商品 promotion_type 及促销时间窗（promotion_start_time /
  promotion_end_time），促销结束后恢复原价 price。
- 「满减能和优惠券一起用吗」→ 可以：满减为商品级（pms_product_full_reduction），
  优惠券为订单级，二者可叠加。
- 「积分能抵多少」→ 每 100 积分抵 1 元，单笔订单最高抵 50%，且须按 100 的整数倍使用。
- 「限时购限购吗」→ promotion_per_limit 为活动限购数量，超出部分按原价计算。
- 「优惠是怎么算的」→ 按第 6 节顺序计算，可引用订单各优惠金额字段向用户解释。
